# Sistema de biblioteca

A ideia do sistema de biblioteca é resolve o problema da entrega e empréstimo de livros caso a data da devolução cai em um feriado e se isso acontece a devolução é adicionada mais um dia, por exemplo, entrega 26/09/2026 (dia de feriado) a entrega será para dia 27/09/2026 a data de devolução não pode em dia útil.

Também deve guarda o nome de usuário, senha e e-mail e quantidade de estoque de livros e se usuário ainda pode pega a obra emprestador.

ações da biblioteca
- Empresta
- Prazo de devolver o livro
- Nome de livro
- Nome do autor
- Quantidade de livros

Na biblioteca os usuário podem ler os livro pegar emprestado 

Observação: também será adicionador se usuário concluiu ou desistiu da leitura, e quantidade de livro emprestados e a penalidade se o empréstimo da entrega livro estive atrasado.
